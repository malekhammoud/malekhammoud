## The problem

This one is on the site for an honest reason: it's the only thing I've built
that a thousand strangers chose to install, and download counts are harder to
argue with than adjectives.

The actual problem was that Minecraft's movement system has no concept of
aerodynamics. Things fall, or they don't. Building an aircraft that flies
because of how it's shaped means adding a flight model to a game that doesn't
have one.

## The constraint

Modding is programming inside someone else's assumptions:

- **You don't own the game loop.** Your physics has to run inside ticks
  scheduled by the engine, at the engine's rate.
- **Multiplayer means two of everything.** The client predicts, the server
  decides, and any disagreement between them shows up as an aircraft that
  visibly teleports.
- **The player's mental model matters more than realism.** A physically
  faithful flight model that feels bad to fly is a failed feature.
- **It has to survive updates** to both the game and the mod loader.

## What I built

A **Fabric API** mod in Java implementing:

- **A flight model** with throttle, yaw and pitch, and — the part that makes it
  feel like flying rather than gliding — a genuine takeoff speed. Below it you
  are a vehicle on the ground; above it you are an aircraft. That threshold is
  the whole design.
- **Player-built airframes**, so the aircraft is something you construct rather
  than an item you're given.
- **Control bindings** that map to the intuition people already have: W/S for
  throttle, A/D for yaw, mouse for pitch.
- **Client-server synchronisation** of aircraft state, so multiplayer flight
  doesn't dissolve into rubber-banding.

## The outcome

**1,070 downloads**, and a demo video that explains it better than this page
does.

## Why it's on this page

Two reasons, and I'd rather say them than dress it up.

First, real-time simulation running inside a fixed tick budget with client-server
state reconciliation is a legitimately hard problem, and it's the same problem
as any system where a prediction and an authority have to agree.

Second, it shipped, and people used it. A lot of engineering portfolios are
things that were built. This is a thing that was released, and then maintained
while a thousand people ran it.
