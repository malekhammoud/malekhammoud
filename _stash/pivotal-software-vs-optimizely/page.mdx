The platform's service-based architecture enables network slicing and multi-access edge computing (MEC), making it ideal for operators requiring high-performance, scalable network functions with minimal disruption to existing packet core networks.

With Mavenir's Converged Packet Core integration, Pivotal Software offers operators a flexible migration path to 5G without requiring complete network overhauls.
